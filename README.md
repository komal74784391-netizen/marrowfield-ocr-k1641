# Marrowfield OCR

Open implementation of the Marrowfield document OCR pipeline, including text detection and field post-processing.

**Repository Status:** Released (v1.6.0, published 2026-06-02)

## Contents

- `src/marrowfield/detector.py`
- `src/marrowfield/postprocess.py`
- `requirements.txt`

## Quick start

```bash
pip install -r requirements.txt
python -m marrowfield.detector --image scan.png
```
